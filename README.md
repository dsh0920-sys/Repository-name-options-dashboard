# 나스닥 옵션 대시보드

QQQ(나스닥100)와 NVDA(엔비디아)의 옵션 포지셔닝을 매일 자동으로 정리해 보여주는 페이지입니다.

- **보는 곳**: `docs/QQQ.html`, `docs/NVDA.html` (GitHub Pages로 공개)
- **자동 갱신**: GitHub Actions가 미국 정규장 시간 동안 30분마다, 그리고 장 마감 후 한 번 더 실행합니다.
- **데이터**: 야후 파이낸스(주가·옵션체인), OCC(계좌유형별 거래량). 주가는 15~20분 지연이고, 옵션 계약 수는 하루 한 번만 갱신됩니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `collect.py` | 옵션체인·가격 수집, 주요 레벨과 지표 계산 |
| `flows.py` | 일별 스냅샷을 이어붙여 콜·풋 자금 유입·이탈 계산 |
| `make_dashboard.py` | HTML 대시보드 생성 |
| `explain.py` | 각 항목의 초보자용 해설문 |
| `outlook/` | 종목별 전망 메모(사람이 작성) |

## 주의

정보 제공 목적이며 투자 자문이 아닙니다. 매매 판단과 책임은 이용자 본인에게 있습니다.

1년치 과거 데이터로 검증한 결과, 보험이 몰린 자리(콜월·풋월)와 맥스페인은 지지·저항 예측력이 확인되지 않았습니다. 변동성 구간(감마) 지표만 유효했습니다. 대시보드 안의 "성적표"에 그 결과가 표시됩니다.
